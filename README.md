# Growthryders website

Static website for Growthryders (growthryders.in). Plain HTML, CSS and JavaScript, no framework.

- `build.py` holds all page content and generates the pages into `site/`. Run `python3 build.py` after editing copy.
- `site/` is what gets published (GitHub Pages serves this folder's contents from the repository root).
- `site/assets/films/` holds the web versions of the campaign films and their posters.
- `site/CNAME` sets the custom domain.
